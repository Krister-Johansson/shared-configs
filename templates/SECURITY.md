# Security Policy

## Supported versions

Only the latest release of {{PACKAGE_NAME}} receives security fixes. The project
follows semantic versioning; upgrade to the newest version before reporting.

## Reporting a vulnerability

Please report vulnerabilities **privately** via
[GitHub Security Advisories](https://github.com/{{REPO_SLUG}}/security/advisories/new) —
do not open a public issue.

You can expect an acknowledgement within **5 business days**.
